## MPPI 플래너 준비본

MPPI 플래너·제어기 패키지와 race_stack 변경 패치를 모은 준비본이다. 기본 비활성인 정지 해소 기능은 shield 정지 상태의 제한된 조건에서 저속 이동을 시도한다. [구현과 오프라인 검증](docs/2026-11-25-stuck-release-impl.md)을 참고한다.

Berlin, PF 측위, 속도 배율 0.7, seed 2027–2038, 장애물 1·3·5개 시험에서 유효 33설정 중 25설정이 10랩을 완주했고 충돌은 7건이었다. [조건과 무효 판정, 제한](docs/2026-11-25-stuck-release-sim36.md)을 함께 확인해야 한다. 다른 조건에서의 안전성이나 최종 평가 성적을 보장하지 않는다.
